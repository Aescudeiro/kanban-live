# @kanban-live/web

React + Vite frontend for [kanban-live](../../README.md): the board UI,
kept in sync across clients over WebSockets.

```bash
pnpm dev    # start the Vite dev server
pnpm test   # component tests (Vitest + Testing Library)
```

Shared domain types and event contracts come from
[`@kanban-live/shared`](../../packages/shared).
